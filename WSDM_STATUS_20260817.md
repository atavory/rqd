# WSDM 2027 Shutdown Status

Date: 2026-08-17

## Decision

Shut down the current WSDM 2027 submission effort. Do not continue autonomous
experiment loops for this submission. The current generative-recommender story
is not strong enough to repair in the remaining submission window.

The repository state is preserved because the results still contain useful
evidence for a later paper, especially around retrieval-style semantic-ID
interfaces and new-item compatibility. It should not be cited as a completed
WSDM claim.

## What Changed

The last round added target-item split evaluation for the end-to-end generator
and the learned context reranker. It separates target items into carried-over
items and new target items whose source-period embedding is zero. It also adds
new-item graft baselines that preserve existing IDs while encoding new items
with a refreshed tokenizer, plus queue scripts and CSV export for those rows.

This was the right diagnostic because the earlier setup measured an unfavorable
case: a frozen generator and mostly existing items. In generative recommenders,
semantic IDs are the output vocabulary. Updating item IDs without updating or
compatibly constraining the generator can hurt routing and ranking even when
reconstruction improves.

## Evidence That Survived

There are premise-aligned positives on new items under the end-to-end generator.
The strongest full-size rows are:

- Amazon 2018 Electronics, funnel24, freeze depth 2, seed 0, new items
  (`n=5330`): stratified improves NDCG@10 from `0.001586` to `0.002710`
  (`+70.9%`) and recall@10 from `0.003189` to `0.005066` (`+58.8%`) with
  zero churn. New-item full grafts are stronger, up to `0.007517` NDCG@10 and
  `0.012946` recall@10, but their cost and ID semantics need separate framing.
- Amazon 2018 Electronics, funnel24, freeze depth 3, seed 0, new items
  (`n=5330`): stratified improves NDCG@10 from `0.001677` to `0.002520`
  (`+50.2%`) and recall@10 from `0.003002` to `0.004128` (`+37.5%`) with the
  same routing coverage as frozen.
- Amazon 2023 Electronics, funnel24, freeze depth 2, seed 0, new items
  (`n=7393`): stratified gives a small positive (`+5.7%` NDCG@10,
  `+8.8%` recall@10) with zero churn; graft and low-churn relabel variants are
  stronger.
- Scout rows found additional positives on Amazon 2023 Books and some funnel16
  configurations, especially for new-item grafting.

These results support a narrower thesis: new-item semantic-ID repair can help
when the old tokenizer cannot represent new catalog geometry and the prefix
interface remains compatible.

## Evidence That Failed

The broad ranking claim failed. Learned context-reranker rows are mixed to
negative, and in several rows frozen remains better than stratified or grafted
variants. This undercuts the claim that suffix repair generally improves
downstream ranking under an old consumer.

Two failure modes matter:

- Routing coverage collapse: refreshed/full item prefixes can no longer match
  prefixes generated by the old model. In some freeze-depth-3 rows coverage drops
  from about `0.589` to about `0.053`.
- Within-bucket ranking loss: stratified can preserve coverage but still move
  decoded item vectors in a direction the old scorer or reranker does not use
  well.

Absolute NDCG values are also small, and the late-stage experiment set is broad
enough that continuing to chase a headline would risk overfitting the story to
the matrix.

## Interpretation

The useful distinction is not "stratified wins ranking." The correct systems
view is:

- `frozen`: cheapest and often best when the old generator/scorer still matches
  existing item IDs and geometry.
- `stratified`: preserves the stable prefix and can repair new-item
  representations at zero prefix churn, but it is not automatically better for
  an old generator.
- `full retrain` or relabel: can recover quality but changes the output
  vocabulary/interface unless relabeling is explicitly constrained and audited.
- `new-item graft`: promising for a future paper because it preserves existing
  IDs while giving new items a refreshed representation, but it needs a clean
  cost and serving model.

For generative recommenders, semantic-ID updates are output-vocabulary updates.
That is a WSDM-relevant angle, but the current paper does not yet have the
method or evidence needed for submission.

## Future Direction

The likely salvage path is not a six-day fix to the current generative paper.
It is a later paper on semantic-ID compatibility for retrieval and generative
interfaces:

- treat semantic IDs as serving interfaces, not just reconstruction artifacts;
- report prefix coverage, churn, update cost, and new-item quality separately;
- preserve existing IDs by default;
- repair or graft new items under a compatibility gate;
- use generative-recommender results as an interface-vocabulary case study, not
  as the main ranking-win claim until a compatible retrained generator exists.
